# ХимПро v8 — печатные этикетки партий

Основано на v7. После входа откройте **Этикетки** (`/labels`), выберите партию и размер: 100 × 70 мм или 100 × 150 мм. Нажмите «Печать / сохранить PDF». В диалоге браузера отключите колонтитулы и установите масштаб 100%.

Статус вычисляется **при открытии**: просрочено → заблокировано → карантин → истекает срок (только если ОТК разрешил) → разрешено. Порог предупреждения 30 дней. Дата и время печати выводятся на этикетке; после изменения статуса распечатанные наклейки необходимо заменить.

QR-код по умолчанию содержит идентификатор `CHEMPRO:LOT:<код партии>`. Если установить переменную окружения `PUBLIC_BASE_URL=https://ваш-домен`, QR будет вести на `/trace?lot=...`. Для просмотра требуется авторизация. Не задавайте HTTP-адрес для производственной среды.

**Внимание:** это внутренние идентификационные этикетки, **не** обязательная транспортная или потребительская маркировка химических веществ. Для опасных химикатов потребуются отдельные обязательные поля, пиктограммы, предупредительные фразы и проверка нормативных требований применимой юрисдикции.

## Установка

Замените файлы в GitHub содержимым архива (сохраните копию БД). Зависимость `qrcode` добавлена в requirements.txt. Не разворачивайте на производстве до проверки деплоя, HTTPS и постоянного хранения БД.
