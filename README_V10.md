# ХимПро v10 — операции с тарой

Добавлен раздел `/container-ops`: перемещение тары между местами хранения, инвентаризационная корректировка количества, история операций и аудит.

## Важно
- Версия **не** осуществляет автоматического списания из конкретной тары при производстве и отгрузке. Эти операции остаются на уровне партии.
- Инвентаризационная корректировка тары не меняет остаток партии; расхождения должны разбираться отдельно.
- Нельзя увеличить суммарное количество зарегистрированной тары сверх остатка партии.
- Операции доступны ролям admin и warehouse.
- Перед обновлением сохраните базу SQLite. В App Platform требуется постоянное хранилище, иначе данные могут потеряться при пересоздании контейнера.
- Для химического производства требуются дополнительные проверки, тесты и обязательная маркировка опасностей.

## Установка через GitHub
Загрузите файлы архива в корень репозитория, заменив существующие; Timeweb автоматически соберёт новый коммит, если включён автодеплой. Сначала проверьте на тестовом окружении.
