# ХимПро v12 — Urovo CT48 (браузер)

Новый маршрут `/tsd` — адаптивное рабочее место кладовщика для Chrome на Urovo CT48. Нужны вход под ролью `warehouse`/`admin`, сеть и HTTPS. В ScanWedge включите передачу скана как ввод с клавиатуры (Keystroke/HID), суффикс Enter. Фактические названия пунктов зависят от прошивки.

Сканирование **только ищет тару**. Далее оператор выбирает перемещение или частичный расход и подтверждает операцию отдельно. Для каждого подтверждения сервер выдаёт одноразовый токен, который записывается в SQLite; повторное подтверждение с тем же токеном отклоняется. Операции проходят внутри `BEGIN IMMEDIATE`, с аудитом и повторной проверкой остатков, статуса ОТК и срока годности.

Расход доступен только для разрешённого ОТК непросроченного сырья; остатки тары и партии уменьшаются одновременно. Это **расход вне производственного задания**. При пропадании сети офлайн-очередь не используется. Режим камеры и общий экран `/scan` из v11 сохранены; для CT48 рекомендуется `/tsd`.

## Обновление

1. Сделайте резервную копию SQLite и текущего кода.
2. Разверните ZIP в тестовой среде, не удаляя существующую БД и её постоянный том.
3. Проверьте `/health`, затем `/tsd` и сканирование тестовой тары.
4. Проверьте повторное нажатие «Подтвердить»: повторного списания быть не должно.
5. Только после приёмочных испытаний переносите на рабочий контур.

## Ограничения

Функциональные HTTP-тесты требуют установленного Flask. В исходной версии есть другие пути операций с тарой, которые следует унифицировать с идемпотентными токенами до производственной эксплуатации. Не реализованы офлайн-операции, привязка расхода к производственному заданию и полноценная приёмка по ТСД. Маркировка не заменяет GHS/CLP.
