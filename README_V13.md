# ХимПро v13 — Urovo CT48: приёмка тары и подбор по заданию

Откройте `/tsd/receive` для регистрации отдельной тары в **уже оприходованной** партии сырья. Это не заменяет документ поступления закупки и не увеличивает остаток партии. QR тары: `CHEMPRO:CONTAINER:<код>`; QR адреса: `CHEMPRO:LOCATION:<адрес>`. ScanWedge CT48: keyboard output, суффикс Enter.

`/tsd/pick`: сканирование тары и адреса для подбора под утверждённое производственное задание с предварительным резервом партии. Транзакция `BEGIN IMMEDIATE`, ключ запроса защищает от повторного проведения, проверяются ОТК, срок годности, адрес и свободный остаток. Подбор НЕ списывает сырьё и НЕ завершает производственное задание. Старый путь расхода `/tsd` теперь не позволяет потратить количество, уже отобранное для задания.

**Ограничения:** списание подобранной тары в производстве пока не интегрировано; старые пути изменения остатков партии не учитывают таблицу подбора. Не использовать в промышленной эксплуатации без интеграционных испытаний и проверки всех маршрутов списания.

Обновление: сделайте резервную копию SQLite и тестируйте отдельно от производства. `init()` добавляет `tsd_picks` автоматически. Требуются HTTPS, постоянное хранилище SQLite и проверка ScanWedge на физическом CT48.
