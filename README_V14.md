# ХимПро v14 — выдача сырья по производственному заданию

## Новое
- `/tsd/issue`: выдача полностью подобранной тары в производство на Urovo CT48 через Chrome/ScanWedge (HID).
- Состояния подбора: `staged` → `issued` → `consumed`.
- Проверка полного соответствия выданной тары резервам каждой партии.
- При проведении выпуска по заданию: атомарное списание из каждой выданной тары и соответствующей партии, записи в `container_operations`, `movements`, `consumptions`.
- При выдаче количество **не уменьшается**; оно уменьшается только при выпуске. Повторный выпуск по закрытому заданию запрещён.
- Защита выдачи одноразовым `request_key` и `BEGIN IMMEDIATE`.

## Порядок работы
1. Утвердить задание и создать резервы сырья.
2. Через `/tsd/pick` подобрать конкретные канистры по QR и местам хранения.
3. Через `/tsd/issue` подтвердить выдачу, когда подобрано ровно столько, сколько зарезервировано.
4. Оператор проводит выпуск в `/production` по тому же заданию. Только тогда списываются тара и партии.

## Ограничения
- Фактический расход по рецептуре равен плановому резерву; отдельный учёт отклонений и возвратов из производства не реализован.
- Для производственных заданий без зарегистрированной тары сохраняется старый маршрут списания партии.
- Не реализованы физические сканирования при передаче из склада оператору, электронная подпись при передаче и офлайн-режим.
- Складской учёт по месту хранения остаётся учётом местоположения, а не полноценным складским балансом.
- Тестирование на реальном Urovo CT48 и HTTP интеграционные тесты не выполнены. Сначала тестовый стенд и резервная копия БД.
