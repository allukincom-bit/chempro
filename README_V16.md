# ХимПро v16 — сверка остатков и нормативного расхода

Новый маршрут `/reconciliation` доступен ролям admin, warehouse, technologist, operator. Только чтение.

## Сверка склада
Сравниваются остаток партии и сумма количеств **активной** тары. Партии без тары помечаются «Тара не учтена», а не ошибкой. Положительный остаток у неактивной тары выделяется как ошибка данных. Разница не исправляется автоматически.

## Сверка производства
Для последних 100 выпусков норматив = **плановый выпуск** × процент компонента из рецептуры. Учтённый расход = сумма записей consumptions по материалу. Отклонение = учтённый − норматив. Это не результат независимого взвешивания.

## Безопасность и ограничения
Отчёт не меняет базу данных. Доступ только после авторизации. ТСД Urovo CT48 продолжает работать через браузер и ScanWedge (режим клавиатуры). Полная интеграционная проверка и тесты на CT48 обязательны перед внедрением. Сначала резервная копия SQLite и тестовая среда.
