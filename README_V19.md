# ХимПро v19 — ввод после смены и сканы оригиналов

Основа: v18. Новое: пакетное заполнение параметров производственного листа с указанием фактического времени каждого измерения; счётчик обязательных точек; загрузка PDF/JPEG/PNG бумажного оригинала (5 МБ, максимум 10 файлов) с хранением в SQLite, SHA256 и защищённой авторизованной выдачей.

Маршруты: `/production/sheets/<id>` и `/production/sheets/<id>/attachments/<attachment_id>`. Пакетный ввод доступен только в статусе issued. Значения записываются атомарно в SQLite; для отклонений обязательны пояснения.

Ограничения: заполнение через браузер CT48 или ПК; сканер работает в клавиатурном режиме. Файлы сохраняются в базе, поэтому увеличивается размер резервной копии. Система не выполняет автоматическое списание сырья. Снимки документов не являются юридически значимыми электронными подписями.

Перед тестовым обновлением сделайте резервную копию SQLite. HTTP-тесты и испытания на CT48 необходимы до эксплуатации.
