# ХимПро v20 — Пульт технолога

Добавлен `/production/dashboard`: сводка по производственным листам, фильтры по статусу и проблемам, поиск по номеру, партии и продукции. Отображаются обязательные контрольные точки, нерассмотренные отклонения, регистрация бумажного оригинала и количество приложенных сканов.

**Доступ:** администратор, технолог, ОТК и роль просмотра. Операторы используют `/production/sheets` и `/tsd/production`. Пульт не меняет записи или остатки.

**Правило расчёта:** для каждого параметра используется последняя запись; нерассмотренное отклонение — последняя запись за пределами допуска без решения «принято». Отсутствующий бумажный оригинал или обязательные значения помечаются как требующие внимания. Статус «готов» — индикатор заполненности, не автоматическое разрешение выпуска.

**Установка:** сначала резервная копия SQLite, затем тестовый стенд Timeweb. Приложение требует постоянного тома для SQLite, HTTPS и устойчивого `SECRET_KEY`. Реальный Urovo CT48 и полный HTTP-регресс пока не испытаны.
