# ХимПро v21 — план смены

Новые страницы: `/production/shift-plan` (планирование технологом), `/tsd/shift-plan` (задания на текущий день для оператора Urovo CT48).

Технолог назначает утверждённое производственное задание оператору, задаёт дату смены и плановый интервал (до 24 часов). Назначение уникально для задания. Отметки начала и окончания ставит технолог; время фиксируется сервером, история хранится в `shift_events` и `audit`.

Просрочка рассчитывается по плановому окончанию, если фактическое окончание не отмечено. Время зависит от часов сервера; часовой пояс и смены через полночь требуют отдельной настройки для предприятия.

Оператор видит свои задания через браузер ТСД; данные измерений вносятся в существующий производственный лист. План смены не меняет складские остатки и не закрывает производственные листы.

**Ограничения:** одна смена/один оператор на задание, нет переназначения и отдельных планов каждого этапа. Для эксплуатации сначала испытать на тестовой базе, сохранить резервную копию SQLite, проверить часы сервера и права.
