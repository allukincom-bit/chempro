# ХимПро v22 — поэтапный план смены

Новые маршруты: `/production/stages` (план технолога) и `/tsd/stages` (этапы на Urovo CT48 через браузер).

1. Технолог создаёт назначение на смену в `/production/shift-plan` и выпускает производственный лист.
2. В `/production/stages` выбирает назначение и создаёт **предварительный** план этапов из зафиксированного снимка ТК.
3. Время в первой версии **распределяется равномерно** между этапами, а не рассчитывается по реальным нормативам; перед использованием технолог обязан проверить план.
4. Оператор отмечает начало и завершение этапа в `/tsd/stages`. Повторное проведение блокируется.
5. Все события фиксируются на сервере в `shift_stage_events`. Измерения, QC, бумажные записи и складские остатки не меняются.

Ограничения: нет редактора длительности отдельных этапов, автоматической проверки последовательности и работы без сети. Не используйте отметку завершения этапа как разрешение перехода при незавершённом контроле качества. Испытайте на копии БД и реальном CT48 перед эксплуатацией.
