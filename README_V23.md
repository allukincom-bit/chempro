# ХимПро v23 — контроль фактической загрузки через Urovo CT48

Маршрут: `/tsd/load`. Работает в браузере Chrome и со ScanWedge в режиме Keyboard/Keystroke + Enter.

## Процесс
1. Технолог утверждает рецептуру, выдаёт задание и производственный лист.
2. Кладовщик резервирует, подбирает и выдаёт конкретную тару через `/tsd/pick` и `/tsd/issue`.
3. Оператор выбирает задание и компонент, сканирует QR тары, вводит вес и время взвешивания, подтверждает запись.
4. Сервер проверяет материал по ТК, разрешение ОТК, срок годности, выданное количество, остаток доступного выданного количества и норматив.
5. Запись добавляется в отдельный журнал; **складские остатки не меняются**. Списание остаётся в существующем механизме выпуска партии.

## Ограничения и безопасность
- По умолчанию допуск к превышению нормы **0%**; произвольный допуск без утверждения технологом не применяется. Превышение блокируется.
- Время фактического взвешивания вводится оператором, время внесения сохраняет сервер.
- Каждая запись имеет одноразовый ключ; повторное проведение блокируется в БД.
- При выпуске производственного задания старый механизм списания пока **не сверяет** журнал v23 автоматически: нельзя считать его источником бухгалтерского списания или заменой весов.
- Для старых производственных листов сопоставление компонента выполняется по названию из зафиксированного снимка ТК; для новых — по идентификатору материала.
- Нет автоматического импорта показаний весов. Значения вводятся вручную.
- Перед применением в производстве — резервная копия SQLite, тестирование прав и реальный прогон на CT48.
