# ХимПро v24 — сверка фактической загрузки

Новый раздел: `/production/load-reconciliation` (администратор, технолог, ОТК, кладовщик, просмотр).

Сопоставляет снимок ТК производственного листа, выдачу по ТСД (`tsd_picks` со статусами `issued`/`consumed`) и фактическую загрузку (`material_loads_v23`). Показывает отклонения и причины для проверки. Не меняет остатки, не подтверждает выпуск и не закрывает задание.

**Ограничения:** учёт выдачи через старые маршруты может не попасть в колонку «Выдано»; не все исторические записи содержат ID материала в снимке ТК, поэтому для них используется уникальное совпадение по наименованию. После завершения задания исторические данные о возвратах могут быть неполными. При несовпадении нужен разбор первичных документов. Десятичные величины в старой схеме SQLite хранятся как REAL, поэтому для точных весовых операций в будущем нужен переход на Decimal/целочисленные единицы.

## Развёртывание
1. Сделайте резервную копию базы SQLite и каталога данных.
2. Разверните v24 на отдельном тестовом приложении с копией базы.
3. Проверьте конкретные задания: частичная выдача, возврат, неполная загрузка, завершённый выпуск.
4. Проверьте права доступа и работу браузера на Urovo CT48.
5. Не используйте как основание для автоматического списания до интеграционных испытаний.
