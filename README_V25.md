# ХимПро v25 — лабораторные пробы ОТК

Основа: v24. Новый раздел `/quality/samples` для проб сырья и готовой продукции.

1. Создайте нормы на `/quality` для соответствующей номенклатуры.
2. Зарегистрируйте пробу: уникальный код, партия, время отбора, отборщик.
3. Введите измерения по каждому действующему показателю. pH, плотность, вязкость и любые другие параметры задаются в нормах.
4. Сотрудник ОТК рассматривает пробу. При соответствии всем нормам результаты переносятся в существующий журнал ОТК; выпуск партии из карантина производится отдельно вручную.
5. При отрицательном результате выпущенная партия переводится в карантин; отрицательную пробу нельзя подтвердить как соответствующую.

Ограничения: лабораторный журнал не заменяет валидацию методик и протоколы испытаний; после подтверждения не реализовано юридически значимое подписание; нет автоматического паспорта качества. При изменении норм требуется новый анализ. Время отбора вводится вручную, время регистрации фиксирует сервер. Испытайте на тестовой копии SQLite, затем проверьте физический Urovo CT48. Не выкладывайте в производство без проверки.
