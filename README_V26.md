# ХимПро v26 — паспорта качества готовой продукции

Основа: v25. Раздел `/quality/passports` (доступен после авторизации).

## Порядок работы
1. В `/quality` настройте действующие нормы ОТК готовой продукции.
2. В `/quality/samples` зарегистрируйте пробу, измерьте все обязательные показатели и подтвердите её сотрудником ОТК.
3. Уполномоченный сотрудник вручную переводит партию в статус `released` в разделе партий.
4. В `/quality/passports` выпустите паспорт. Выпуск разрешён только для готовой продукции со статусом `released`, неистёкшим сроком годности и подтверждённой последней пробой, отвечающей текущим нормам.
5. Откройте печатную A4-версию и используйте печать браузера / «Сохранить в PDF». Повторная печать использует неизменяемый снимок результатов. Номер паспорта вида `ПК-000001`.

## Контроль
- Только роли `admin` и `quality` могут выпускать паспорт; просмотр — для авторизованных пользователей.
- Повторный выпуск по той же пробе запрещён; можно печатать существующий паспорт.
- После перевода партии в карантин, блокировки или истечения срока годности архивная печать содержит предупреждение о текущем состоянии.
- Действия по выпуску фиксируются в `audit`. Запись в БД создаётся атомарно.

## Ограничения
- Это внутренняя форма, а не автоматически юридически действительный сертификат. Проверьте требования к паспортам и полномочиям подписанта для своей продукции и рынка.
- Приложение генерирует HTML для печати A4; PDF сохраняется средствами браузера, серверный PDF-генератор не добавлен.
- Нет автоматического отзыва ранее выданных паспортов при изменении спецификаций: для архивного документа отображается текущий статус партии, но не текущая редакция спецификации.
- Обязательны тестовый стенд, резервная копия SQLite и интеграционные испытания до эксплуатации.
