# ХимПро v28 — QR-отгрузка готовой продукции через Urovo CT48

Основа v27. `/tsd/ship` — отгрузка **целых** единиц тары после фасовки. Кладовщик/администратор сканирует QR `CHEMPRO:CONTAINER:<code>` в поле, по одному коду в строке (ScanWedge/Keystroke + Enter), указывает клиента и проводит операцию.

## Инварианты
- Только зарегистрированная фасовка ГП, одна партия в одной операции, 1–100 уникальных кодов.
- Только активная тара с положительным остатком, партия `released`, срок годности не истёк.
- `BEGIN IMMEDIATE`: одновременно `lots.qty -= total`, `containers.qty=0, active=0`, запись `shipments`, `movements`, детализация QR и `audit`. При ошибке откат целиком.
- `request_token` уникален, повторная отправка не списывает остатки второй раз.
- Старый маршрут `/shipments` блокирует отгрузку партии, если в ней есть тара с положительным остатком. Нефасованный остаток можно отгружать старым маршрутом только когда тара с остатком отсутствует.
- Сохранены неизменяемые строки детализации отгруженной тары, печатный/просмотровый отчёт `/tsd/ship/<id>`.

## Ограничения
- Нет частичного отпуска из одной канистры/бочки, сканирование само по себе не списывает товар — только подтверждение формы.
- Требуется интеграционное тестирование на копии SQLite, проверка всех сторонних путей изменения остатков, и тест физического Urovo CT48.
- Перед развёртыванием Timeweb — резервная копия БД, постоянный диск, тестовый стенд. Не используйте как единственный источник учёта без приёмочных испытаний.
