# ХимПро v30 — акты брака возвращённой продукции

Добавлен раздел `/quality/disposal-acts` и печатная форма `/quality/disposal-acts/<id>`.

- Создание только для возвратов v29 со статусом `rejected`.
- Одна запись акта на возврат; транзакция BEGIN IMMEDIATE, уникальный индекс, аудит.
- Способ: утилизация / уничтожение / передача подрядчику. Для подрядчика обязательны название и внешний документ.
- Печать A4 / сохранение PDF средствами браузера.
- Роли: admin/quality оформляют, technologist/viewer просматривают.
- **Складские остатки не меняются:** забракованные возвраты никогда не восстанавливались в остатке партии.
- Акт является учётной записью; факт уничтожения подтверждается внешними документами и подписями.

**Ограничение:** повторный цикл отгрузка→возврат→повторная отгрузка одного QR пока НЕ поддерживается: ограничения UNIQUE в таблицах v28/v29 требуют отдельной миграции истории событий. Не снимайте их вручную.

## Развёртывание
Сохраните резервную копию SQLite; разверните в тестовом окружении Timeweb; проверьте миграцию, CSRF, роли и печать. `init()` создаёт таблицу при запуске entrypoint. Не заменяйте рабочую базу архивом.
