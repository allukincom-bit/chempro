# ХимПро v32 — многопозиционные задания на отгрузку

Маршруты: `/dispatch/v32`, `/dispatch/v32/<id>`, `/dispatch/v32/<id>/report`.

Экономист создаёт одно задание с несколькими партиями (по одной строке на партию). Кладовщик принимает его, отгружает целые QR-единицы по выбранной строке несколькими операциями и прикладывает фото автомобиля. Каждая частичная операция атомарно списывает тару и партию через существующий механизм v28. Закрытие возможно только после полного выполнения всех строк и загрузки минимум одного фото. После закрытия фиксируется снимок отчёта, дальнейшие операции запрещены. Печать A4 / PDF средствами браузера.

Формат строк при создании: `ID_партии;количество`, каждая на отдельной строке. До 30 строк и до 100 QR за операцию. Суммарный остаток проверяется при каждой отгрузке, создание задания не резервирует товар. Повторное проведение с тем же ключом не списывает остаток повторно. Старые задания v31 с shipment_id защищены от повторной отгрузки через v32.

Внимание: v31-форма `/dispatch/tasks/<id>` остаётся доступной для старых заданий. Для новых многопозиционных заданий использовать только `/dispatch/v32/<id>`; перед промышленным запуском ограничьте старую форму и проверьте интеграцию. Фотографии хранятся в SQLite. Перед установкой — резервная копия базы и тест на копии Timeweb. PDF — печать браузера, не серверная генерация. Нужны интеграционные испытания с Flask и CT48.
