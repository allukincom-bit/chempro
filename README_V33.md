# ХимПро v33 — совмещение ролей

Основа: v32. Администратор: `/users`, чекбоксы для нескольких ролей одному сотруднику. Один и тот же тип роли назначается любому числу сотрудников. Поддерживаются экономист, технолог, оператор (аппаратчик), ОТК, кладовщик, просмотр.

Таблица `user_roles_v33` создаётся при `init()`. Существующие роли автоматически переносятся без удаления пользователей и паролей. Роли считываются из SQLite при каждом запросе, изменения действуют без повторного входа. В `users.role` остаётся одна совместимая роль для старого кода.

Администратор не комбинируется с другими ролями: у него и так полный доступ. Запрещено снимать администратора с себя или последнего администратора. Изменения журналируются.

**Ограничение:** исторические записи, где оператор определяется единственным полем `users.role`, могут нуждаться в отдельной проверке; новые проверки доступа работают по совокупности ролей. Никакой автоматической электронной подписи не добавлено.

Перед Timeweb сделайте резервную копию SQLite, проверьте права и сценарии на тестовой базе.
