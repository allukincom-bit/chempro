# ХимПро v34 — меню по ролям и персональные настройки

Основа v33. Навигация фильтруется по сумме ролей пользователя. Сотрудник с несколькими ролями видит объединённое меню. Администратор видит все пункты. Настройки конкретного сотрудника: `/profile/menu`, отметка видимых разделов. Настройки хранятся в `user_menu_v34`, создаётся автоматически при `init()`.

**Безопасность:** меню — только навигация; права проверяются обработчиками маршрутов через `@allowed` и другие проверки. Скрытие ссылки не отменяет права, отображение не гарантирует доступ к конкретному действию. Ролевые группы в меню требуют аудита соответствия фактическим разрешениям в существующих маршрутах. CSRF действует для формы настройки.

Установка: резервная копия SQLite, развернуть на тестовой среде Timeweb, проверить миграцию и права всех сочетаний ролей.
