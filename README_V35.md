# ХимПро v35 — матрица прав доступа

Добавлена страница `/admin/permissions` (только администратор). Можно установить запрет или разрешение для роли либо конкретного пользователя. `По умолчанию` удаляет исключение.

## Безопасность

* **Запрет имеет приоритет**: если сотрудник совмещает несколько ролей и для одной роли установлен запрет на действие, оно запрещено. Запрет для пользователя также блокирует действие.
* Разрешение в этой матрице **не расширяет исходные права** `@allowed` и внутренние проверки `has_role`. Администратор имеет полный доступ.
* По умолчанию старые права сохраняются. Ограничения действуют со следующего HTTP-запроса.
* Проверки выполняются на сервере, не только через меню. Изменения записываются в audit.
* Первая версия матрицы охватывает задания v31/v32, фото, пробы/паспорта ОТК, рецептуры. Остальные маршруты сохраняют прежнюю ролевую модель.
* В маршрутах, где несколько операций объединены в одном POST, разделение выполняется по `action`. Перед промышленным применением требуется дополнительный аудит всех вариантов `action`.

## Установка

Сделайте резервную копию SQLite и запустите на тестовой копии Timeweb. `init()` создаёт `permission_overrides_v35`, не удаляя старые данные. Для production используйте `entrypoint:app` через gunicorn. Для CT48 интерфейс не изменён.

## Проверки

`python test_v35_static.py`. HTTP-интеграционные тесты необходимо выполнять в среде с установленным Flask.
