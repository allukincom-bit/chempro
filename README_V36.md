# ХимПро v36 — расширение матрицы прав

## Новое

Администратор: `/admin/permissions`. К прежним 11 действиям добавлено 21 право по складу, операциям CT48, производству, закупкам, возвратам и утилизации. Настройка: роль или ID пользователя → право → Запретить / По умолчанию / Разрешить. Все изменения пишутся в аудит.

**Модель безопасности:** прежние проверки `@allowed` и `has_role` сохраняются. Новые права являются только дополнительным фильтром. Явный запрет у любой совмещённой роли или пользователя имеет приоритет. Администратор по-прежнему имеет полный доступ.

**Разделение чтения и записи:** для смешанных GET/POST маршрутов назначаются отдельные права. Права `tsd.view` и `production.view` не дают права проводить операции. Уточнение: маршрут `/work-orders` имеет отдельную проверку `production.release` для действий `complete` и `release`.

**Ограничения:** карта покрывает основные маршруты перечисленных модулей, но не является универсальным конструктором прав для каждой кнопки и каждого действия. На смешанных POST маршрутах некоторые операции имеют общий write-permission. Настройки видимости меню v34 остаются независимыми от матрицы прав. Протестируйте реальные комбинации ролей и сценарии на стенде.

## Установка

1. Сделайте резервную копию SQLite и хранилища вложений.
2. Разверните ZIP на тестовом Timeweb, сохранив переменные окружения и постоянный том данных.
3. Проверьте вход, меню, ограничения GET/POST, складские операции, CT48 и журнал аудита.
4. Только после успешной проверки обновляйте рабочую систему.

`python test_v36_static.py` — статические тесты; HTTP тесты требуют Flask и окружения приложения.
