# lovetech v37 — обновлённый интерфейс

На базе ХимПро v36. Новый адаптивный серо-белый интерфейс с красными акцентами и названием lovetech. Обновлены общая оболочка, боковое меню с учётом ролей, главная страница с реальными показателями из SQLite, списками заданий, предупреждениями по срокам и графиком отгрузок. Остальные маршруты и бизнес-операции сохранены.

## Установка
Сделайте резервную копию SQLite и SECRET_KEY. Разверните приложение на тестовом окружении Timeweb по существующему Dockerfile, затем проверьте доступы, меню и TSD CT48. Новых таблиц и миграций нет.

## Ограничения
В макете поиска нет полноценного поискового сервиса; поле поиска заменено на информационный элемент. Диаграмма распределения категорий — декоративная, показывает суммарный остаток ГП; она не рассчитывает доли товарных категорий. Сумма по партиям предполагает единицу кг, если используются иные единицы, требуется нормализация.
