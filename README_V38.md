# lovetech v38 — единый интерфейс рабочих разделов

Основа: v37. Логика производства, отгрузки, складских транзакций и модель ролей не менялись.

## Изменения
- Общий светло-серый дизайн с красными акцентами для карточек, форм, таблиц, полей и кнопок.
- Поиск по **доступным пунктам меню** без серверного запроса. Это не поиск по документам или базе.
- Мобильное боковое меню: затемнение фона, закрытие по нажатию вне меню и Escape.
- Улучшенные размеры элементов управления для браузера Urovo CT48 (ScanWedge/Keystroke + Enter). Существующая логика сканирования не изменена.
- Видимая клавиатурная фокусировка, адаптация форм и горизонтальная прокрутка больших таблиц.

## Внедрение
1. Создайте резервную копию SQLite и сохраните SECRET_KEY.
2. Проверьте работу на тестовом экземпляре Timeweb.
3. Проверьте роли, CSRF, реальные отгрузки, приёмку и сканирование QR с Urovo CT48.
4. После тестирования переносите в рабочее приложение.

## Проверки
AST Python, статические проверки интерфейса, компиляция Python, целостность ZIP. HTTP-тесты и физический CT48 в этой среде не запускались.
