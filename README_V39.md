# lovetech v39 — согласование фотоотчёта экономистом

Основа: v38. Новый маршрут `/dispatch/v39/<id>` связан с завершённым многопозиционным заданием v32. После закрытия кладовщик отправляет фотоотчёт на проверку. Экономист подтверждает его либо возвращает с обязательной причиной. После возврата кладовщик добавляет новое фото и повторно отправляет отчёт. История решений и комментариев сохраняется в SQLite.

Правило разделения полномочий: отправивший отчёт или закрывший отгрузку не может её подтвердить, даже если совмещает роли. Доступ: кладовщик/администратор — отправка, экономист/администратор — решение, остальные с разрешённым просмотром — чтение. Проверки на сервере, CSRF и журнал аудита сохранены.

**Важно:** отгрузка v32 уже списывает остатки при сканировании, а закрытие задания предшествует проверке экономиста. Возврат фотоотчёта на исправление **не отменяет отгрузку и не возвращает остатки**. Это согласование документального фотоотчёта, не разрешение на выезд машины. Для контроля до физической отгрузки потребуется отдельное изменение процесса.

Установка: резервная копия SQLite; развёртывание на тестовом Timeweb; проверка ролей, фотографий и переходов статусов. Таблицы создаются в `init()` автоматически. Полноценные HTTP-тесты и проверка на CT48 обязательны до промышленной эксплуатации.
