# lovetech v40 — Глобальный поиск

База: lovetech v39. Маршрут `/search?q=...`, строка поиска в верхней панели. Поиск по продукции, материалам, партиям, производственным заданиям, заданиям экономиста, QR тары и отгрузкам.

## Безопасность
- Только авторизованные сотрудники. Каждая категория проверяется по серверным ролям, включая совмещённые роли, и явным запретам матрицы прав.
- SQL-запросы параметризованы; `%`, `_` и `\` экранируются для буквального поиска.
- До 12 результатов на категорию, не менее двух символов, максимум 100 символов.
- Результаты экранируются Jinja. Поиск не изменяет данные и не предоставляет новых прав.
- Перейти из результата можно в соответствующий раздел (не все разделы имеют адрес отдельной карточки).

## Запуск
Сохраните резервную копию SQLite. Установите зависимости из requirements.txt, задайте CHEM_DB и SECRET_KEY, запустите через entrypoint.py / Dockerfile. Перед производственным развёртыванием проверьте на тестовой базе права и доступность маршрутов.

## Тесты
`python -m unittest test_v40_search.py` — модульные тесты (требуют Flask и qrcode). Остальные test_v*_static.py — статические проверки.
