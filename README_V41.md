# lovetech v41 — печатный производственный лист A4

Версия основана на v40. Печатная форма `/production/sheets/<id>/print` переработана для бумажного заполнения аппаратчиком. Новые разделы: шапка с QR, сырьё (норма/факт/время/подпись), условия цеха, операции и параметры из снимка ТК, контроль качества, замечания, подписи.

- Данные берутся из неизменяемого `production_sheets.snapshot_json`, а не из текущей редактируемой рецептуры.
- Фактические поля в печатном бланке намеренно пустые; демонстрационные значения не подставляются.
- QR использует существующий формат `CHEMPRO:SHEET:<id>` для совместимости со сканерами CT48.
- Печать через браузер A4 или «Сохранить как PDF»; автоматический серверный PDF не создаётся.
- Доступ: авторизованные admin/technologist/operator/quality, без изменения данных.
- Если этапов/параметров много, браузер может перенести продолжение на следующую страницу A4; фиксированное «1 лист» не обещается.
- Для контроля ОТК форма отображает параметры из технологических этапов; лабораторный протокол ОТК остаётся отдельным документом.

## Установка
Сделать резервную копию SQLite, проверить на тестовом Timeweb. Содержимое БД не мигрирует. Печатать через меню «Производственные листы» → «Печать».

## Проверка
`python test_v41_print.py`; HTTP-тесты Flask и физический принтер/CT48 требуют отдельной среды.
