# lovetech v42 — книжная печать производственного листа

Формат печати: **A4, книжная ориентация (210 × 297 мм)**, поля 10 мм слева/справа, 12 мм сверху и 13 мм снизу.

Печатная форма: `/production/sheets/<id>/print`. Настройки закреплены через CSS `@page`, область содержимого ограничена 190 мм, таблицы не выходят за границы листа, заголовки таблиц повторяются при переносе на следующую страницу. Фактические значения по-прежнему заполняются от руки.

В диалоге печати браузера выберите A4 и «Книжная» (если браузер игнорирует CSS @page), масштаб 100%, отключите дополнительные колонтитулы браузера.

Изменена только печатная форма, бизнес-логика и БД без изменений. Перед обновлением на Timeweb сделайте резервную копию и проверьте печать в браузере.

Проверка: `python test_v42_portrait.py`; тесты браузерной печати и физического принтера не выполнялись.
