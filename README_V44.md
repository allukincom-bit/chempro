# lovetech v44 — контроль выполнения производства

Основа: v43. Добавлены страницы `/production/execution` и `/production/execution/<id>` (GET, только чтение).

Отображаются обязательные параметры из сохранённого снимка технологической карты, последние измерения, неразрешённые отклонения, регистрация бумажного оригинала, вложения и сверка нормативного / выданного / загруженного сырья.

**Важно:** расхождения сырья информационные; новая страница не списывает склад, не закрывает лист и не подтверждает ОТК. Старые правила закрытия листа сохранены. Ранее созданные листы с неполным снимком требуют проверки.

## Установка
1. Создайте резервную копию SQLite и папки данных Timeweb.
2. Разверните архив на тестовом стенде с переменной `CHEM_DB` и прежними секретами.
3. Запустите `python -m unittest discover -p 'test_v44*.py'` и существующие тесты.
4. Проверьте HTTP-страницы под ролями аппаратчик, технолог, ОТК, кладовщик и viewer.
5. Проверьте сканирование на CT48 отдельно: v44 не меняет его логику.

`requirements.txt` содержит зависимости приложения. Не заменяйте рабочую БД тестовой.
