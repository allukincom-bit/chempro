# lovetech v45 — Инвентаризация через Urovo CT48

На основе v44. Раздел `/inventory/v45`: создание сессии, сканирование QR тары с вводом фактического количества, обновление повторного скана, расхождения, передача на проверку, закрытие администратором и печать A4.

**Безопасность данных:** модуль НЕ изменяет `lots.qty` и `containers.qty`; закрытие — документальное, не складская корректировка. Ведомость показывает только просканированную тару; отсутствие скана не означает недостачу. Учётное количество фиксируется при первом сканировании. Перед реальной инвентаризацией рекомендуется остановить складские движения в зоне.

CT48: Chrome + ScanWedge Keyboard/Keystroke, суффикс Enter. Ввести QR в поле, затем фактическое количество и нажать «Сохранить подсчёт».

## Развёртывание
1. Сделать резервную копию базы SQLite и данных.
2. Установить на тестовый Timeweb стенд с прежними переменными окружения и постоянным хранилищем `CHEM_DB`.
3. Выполнить `python -m unittest discover -p 'test_v45*.py'`. Для HTTP-тестов установить зависимости `pip install -r requirements.txt`.
4. Проверить роли, CSRF, повторный QR, карантин/неактивную тару, разницу, печать A4 и работу на физическом CT48.
5. После испытаний разворачивать в рабочей системе.
