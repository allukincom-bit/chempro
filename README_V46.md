# lovetech v46 — центр задач и уведомлений

Маршрут `/notifications` — персональная лента задач по совмещённым ролям. События рассчитываются по актуальным документам SQLite, без фоновых процессов и отправки push/email.

Источники: утверждённые производственные задания (аппаратчик/технолог), производственные листы на проверке (технолог), задания отгрузки (кладовщик), открытые пробы и возвраты в карантине (ОТК), фотоотчёты на проверке (экономист), фотоотчёты с замечаниями (кладовщик). Администратор видит все категории.

«Прочитано» — индивидуальная отметка сотрудника в `notification_reads_v46`; она не изменяет статус документа. При смене версии фотоотчёта формируется новый ключ уведомления. Закрытые задачи исчезают из активного списка. Показывается до 120 последних активных задач.

Установка: сохраните резервную копию SQLite, разверните как предыдущую версию через Timeweb App Platform, убедитесь, что `entrypoint.py` вызывает `init()` и создаёт таблицу. Протестируйте с отдельными пользователями разных ролей и с совмещёнными ролями.

Ограничения: это не real-time push; список обновляется при открытии страницы. Нет персонального назначения заданий внутри одной роли; пользователи одной роли видят общий пул задач. Существующие права доступа к конечным документам сохраняются; меню и события не заменяют серверную авторизацию. Не использовать без проверки HTTP на тестовой базе.
