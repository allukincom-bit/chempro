# lovetech v47 — Себестоимость партий

## Развёртывание
На основе v46. Сохраните резервную копию SQLite, разверните архив на тестовом стенде Timeweb, проверьте миграцию таблиц и права пользователей. Инициализация таблиц выполняется через `init()` из `entrypoint.py`.

## Работа
Откройте `/economics/costs` под ролью экономиста или администратора. Укажите учётные цены сырья за единицу в RUB. Откройте выпущенную партию, проверьте списанное сырьё, нормы, введите стоимость упаковки и прочие расходы, зафиксируйте расчёт. Технолог имеет право просмотра. Фиксация необратима в интерфейсе, снимок не пересчитывается при изменении цен.

## Важные ограничения
Это **управленческая оценка**, не бухгалтерский расчёт: цены задаются вручную и одинаковы для всех сырьевых партий одного материала, стоимость тары и накладные расходы вводятся вручную. Фактический расход берётся из `consumptions`, а не из измерений CT48. Плановый расход вычисляется по текущей рецептуре: если её редактировали, исторические нормы могут отличаться. Отсутствующие цены блокируют фиксацию. Система не изменяет остатки и проводки. Для точной себестоимости по закупочным партиям нужен отдельный модуль оценки FIFO/средней стоимости и исторические версии ТК.

## Тесты
`python test_v47_costs.py` — автономные тесты функции расчёта (без Flask), синтаксис и проверка маршрутов. HTTP-проверки требуют установки зависимостей из `requirements.txt`.
