# lovetech v48 — резервное копирование и контроль целостности

Основа: v47. Новая утилита `db_maintenance.py` работает без Flask, **не изменяет** рабочую БД и выполняет SQLite Online Backup API, совместимый с WAL и работающим приложением. Бэкап проверяется на `integrity_check`, внешние ключи и базовые таблицы, после чего атомарно переименовывается. Выводится SHA-256.

## На Timeweb (с доступом к постоянному диску приложения)

1. Убедитесь, что `CHEM_DB` указывает на **постоянный том**, например `/app/data/chem.db`.
2. До обновления v47 → v48 создайте резервную копию из работающего контейнера или через доступ к тому:
   `python db_maintenance.py backup --db /app/data/chem.db --output /app/data/backups/chem-before-v48-20261018.db`
   Имя нового бэкапа должно быть уникальным. Лучше копировать файл бэкапа **за пределы Timeweb** в защищённое хранилище. Не выкладывайте БД в GitHub.
3. Проверьте `python db_maintenance.py check --db /app/data/chem.db` и отдельно бэкап.
4. На тестовом окружении разверните копию БД и v48, проверьте вход, роли, ОТК, отгрузку, CT48 и печать.
5. Только после этого обновляйте production.

## Локальные тесты

`python -m unittest -v test_v48_reliability.py` — тесты SQLite выполняются без зависимостей; HTTP-тест пропускается без Flask/qrcode.

`pip install -r requirements.txt` затем `python -m unittest -v test_smoke.py test_v48_reliability.py` — HTTP-тесты. В тестах создаётся временная БД, рабочая БД не используется.

## Ограничения

- **Не реализовано:** автоматическое расписание резервного копирования, внешнее хранилище, уведомления об ошибках, восстановление из интерфейса, полноценный аудит миграций и end-to-end тестирование CT48. Настройте регулярный запуск утилиты средствами инфраструктуры.
- При `PRAGMA foreign_key_check` старых данных могут обнаружиться ошибки, созданные ранее; утилита завершится ненулевым кодом, не исправляя данные.
- При переходе на новую версию `entrypoint.py` вызывает `init()` при запуске, поэтому резервную копию нужно сделать **до** обновления.
- Тестовая HTTP-проверка охватывает только базовые маршруты/CSRF, а не все права матрицы и все миграции.
