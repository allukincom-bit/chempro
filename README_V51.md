# lovetech v51 — состояние системы и предупреждения

Основа: v50. Добавлены `operations_v51.py` и регистрация маршрута `/admin/system` (только администратор).

## Возможности

- Единая панель: доступность SQLite, результат последней резервной копии и количество ошибок 5xx.
- Автоматический статус после выполнения `python backup_rotation.py`: атомарно записывается `lovetech-backup-status.json` в каталог копий; фиксируется успех/ошибка и факт тестового восстановления.
- При отсутствии, ошибке или устаревании отчёта (старше 36 часов) панель показывает предупреждение.
- Предупреждения сохраняются в SQLite без дублей, администратор может отметить ознакомление (CSRF защищён).
- Нет SMS, email или push: это уведомления внутри приложения при открытии панели.

## Запуск

Задайте `CHEM_DB` и при необходимости `LOVETECH_BACKUP_DIR` (по умолчанию `/app/data/backups`). После развёртывания запустите `python backup_rotation.py --db /app/data/chem.db --directory /app/data/backups --keep 14` по расписанию внешнего планировщика. Каталог должен быть постоянным и доступным для записи пользователю приложения. Не открывайте его через веб-сервер.

При недоступной SQLite сама панель может возвращать ошибку 500: внешний монитор должен отдельно опрашивать `/health/ready`. Результаты резервирования хранятся на сервере; копии также следует вывозить за его пределы. При обновлении обязательно сделать копию базы и проверить на тестовом окружении.
