# lovetech v58 — связка производственного листа, ТСД и выпуска

Основа: v57. **Рабочие обработчики Flask и схема БД не менялись.** Добавлен автономный интеграционный набор `production_stock_link_v58.py` и статические тесты `test_v58_static.py`.

## Проверяемые цепочки

- Утверждённое задание → резерв → регистрация тары → подбор → выдача → производственный лист → фактическая загрузка.
- Сверка норматив / выдано / загружено; частичная загрузка и обнаружение расхождения.
- Выпуск готовой продукции: списание партии сырья и тары, проводки, расход и сохранение истории загрузки.
- Повторный выпуск, повторная загрузка с тем же ключом, несуществующая тара, выдача не завершена, CSRF.
- Никакие тесты не должны подключаться к рабочей SQLite: каждый создаёт временную БД через `TemporaryDirectory` и `mod.DB`.

## Запуск

```bash
pip install -r requirements.txt
python -m unittest -v test_v58_static
python production_stock_link_v58.py
```

Тестовый набор **завершается ошибкой**, если интеграционные тесты пропущены. Для запуска нужны Flask и qrcode. На Timeweb сначала протестируйте копию в отдельном окружении; сделайте резервную копию SQLite перед развёртыванием.

## Ограничения

Тесты проверяют существующее поведение, **не добавляют запрет выпуска при незакрытом листе** и не делают сверку блокирующей. Проверка реального CT48 / ScanWedge + Enter и эксплуатационные HTTP-проверки в Timeweb остаются отдельными этапами. В наборе наследуются шесть тестов v56 и добавлены восемь новых сценариев.
