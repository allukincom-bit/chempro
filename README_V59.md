# lovetech v59 — контроль готовности партии к выпуску

Основа: полный проект v58. Добавлены страницы `/production/release-readiness` и `/production/release-readiness/<order_id>`.

Проверки: утверждённое невыполненное задание, наличие производственного листа, обязательные измерения, рассмотренные отклонения, зарегистрированный бумажный оригинал, закрытие листа технологом, отсутствие тары со статусом `staged`. Сверка нормы/выдачи/фактической загрузки — предупреждение, не блокирующий фактор из-за возможных старых маршрутов складского учёта.

По умолчанию страницы работают только на чтение, **выпуск не блокируется**. Для обязательной проверки в обработчике `/production` задайте `LOVETECH_V59_ENFORCE_RELEASE=1` в переменных окружения Timeweb, **только после проверки полного процесса на тестовой базе**. Контроль выполняется внутри транзакции `BEGIN IMMEDIATE`, перед складскими списаниями. Не влияет на выпуск без привязки к заданию (`order_id=0`): такой выпуск следует отдельно ограничить организационными правилами.

**Внимание:** включение строгого режима требует закрытого производственного листа *до* выпуска, что может не соответствовать вашему текущему порядку работы. Не включайте его без согласования процесса. Закрытие листа не означает разрешение ОТК на реализацию — готовая партия создаётся в карантине.

## Установка

1. Сделайте резервную копию SQLite; разверните архив в тестовом окружении.
2. `pip install -r requirements.txt`.
3. `python -m unittest -v test_v59_readiness.py`.
4. Проверьте страницы под ролями и производственный процесс; только затем обновляйте Timeweb.

Сканирование CT48 и HTTP-интеграция на физическом терминале не проверялись.
