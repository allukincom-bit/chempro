# lovetech v62 — Учёт рабочего времени

Добавлен отдельный раздел `/attendance`. Администратор назначает **одного** ответственного сотрудника из существующих пользователей. Только он может создавать и исправлять записи табеля для всех сотрудников. Администратор может просматривать табель и переназначать ответственного, но не редактировать табель без назначения самого себя. Другие пользователи получают HTTP 403.

Для каждой даты фиксируются статус (работа, выходной, отпуск, больничный, отсутствие), часы, примечание, время и автор изменения. Повторное сохранение изменяет запись, но сохраняет старые и новые значения в `attendance_history_v62`; также используется общий журнал `audit`. Месячные итоги и CSV доступны в том же разделе. Пустые даты не считаются выходными автоматически.

## Установка

1. Создайте резервную копию SQLite и разверните файлы вместо предыдущей версии.
2. Запустите приложение через `entrypoint.py` (как прежде); `init()` создаёт новые таблицы без удаления данных.
3. Войдите под администратором, откройте «Сотрудники → Учёт рабочего времени», назначьте ответственного.
4. Ответственный заполнит табель для каждого сотрудника по дням.

Данные сохраняются в той же SQLite, без внешних сервисов. Учёт носит внутренний управленческий характер: нет автоматического расчёта зарплаты, производственного календаря, ночных/сверхурочных часов и юридически значимого утверждения табеля. При необходимости эти функции можно добавить отдельно.

## Тесты

`python -m unittest -v test_v62_attendance.py`

HTTP-тесты: `python -m unittest -v test_v62_http.py` (нужны зависимости из `requirements.txt`). Перед установкой на Timeweb проверьте права и сценарии на тестовой базе.
