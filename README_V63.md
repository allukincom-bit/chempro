# lovetech v63 — аудит перед обновлением

Основа: lovetech v62. Производственные обработчики и складские операции не изменены.

## Автономная проверка (без Flask)

```bash
python -m unittest -v test_v63_audit
python release_audit_v63.py --output /tmp/v63-routes.json
python release_audit_v63.py --db /app/data/chem.db --output /tmp/v63-release.json
```

`--db` открывает **существующую** базу в режиме SQLite `mode=ro`, проверяет integrity_check, foreign_key_check и основные таблицы. Не вызывает `init()` и не запускает миграции. Проверка маршрутов анализирует Python AST и обнаруживает отсутствующие критические пути; это НЕ полноценная проверка HTTP и прав доступа.

## Интеграционные тесты (на отдельной тестовой БД)

```bash
pip install -r requirements.txt
python role_http_v54.py
python -m unittest -v test_v62_http
```

Перед проверками на Timeweb создайте резервную копию и работайте на тестовом стенде. Никогда не направляйте интеграционные тесты на рабочую SQLite. Физический Urovo CT48 проверяется отдельно.

## Ограничения

В сборочной среде может отсутствовать Flask; статический аудит не заменяет HTTP-прогон. Файл отчёта содержит имена маршрутов и диагностическую информацию, храните его в закрытом каталоге.
