# lovetech v64 — Расширенный табель рабочего времени

Основано на v63, все предыдущие модули сохранены.

## Функции

- `/attendance/advanced` — расширенный табель. Администратор может просматривать и печатать, **редактирует только один назначенный в `/attendance` сотрудник**.
- Графики 5/2 и 2/2 с датой начала цикла и часами за смену.
- Массовое заполнение месяца **только по пустым датам**. Существующие записи (включая отпуск, больничный и ручные исправления) не меняются.
- Ночные часы (часть основных часов) и сверхурочные (отдельный показатель) по датам.
- Закрытие месяца от редактирования, в том числе через старую форму `/attendance`. Ответственный может повторно открыть месяц, событие фиксируется в общем журнале аудита.
- Печать месячной сводки на A4 в книжной ориентации через браузер.
- Сохранена история изменений обычных записей v62, массовое заполнение записывается в неё.

## Ограничения

Праздники не определяются автоматически, график 2/2 строится по циклу от указанной даты. Ночные/сверхурочные часы вводятся вручную и не рассчитывают зарплату. Печатная форма — месячная сводка, не официальный унифицированный табель. Для новых полей дополнительных часов предусмотрен общий аудит операции (без отдельной истории старых и новых значений). Нельзя редактировать закрытый месяц через штатные формы, но прямое изменение SQLite администратором сервера технически возможно.

## Установка на Timeweb

1. Создайте резервную копию SQLite и протестируйте обновление на копии.
2. Разверните проект как прежде через `entrypoint.py` с переменными окружения предыдущей версии.
3. `init()` создаст три дополнительные таблицы SQLite без удаления существующих записей.
4. Администратор назначает ответственного в `/attendance`, ответственный открывает `/attendance/advanced`.
5. Проверьте массовое заполнение, закрытие месяца, печать и ограничения ролей.

## Тесты

`python -m unittest -v test_v64_attendance.py test_v62_attendance.py`

Тесты Flask требуют `pip install -r requirements.txt` и проверки на отдельной тестовой базе. Физическое тестирование на Timeweb не выполнялось.
