# ХимПро v9 — тара, массовая печать и журнал

Новые маршруты: `/containers`, `/containers/<id>/label`, POST `/containers/print`, `/containers/print-log`.

Новые таблицы создаются через `init()` при старте: `containers`, `label_print_jobs`.

Регистрация тары доступна администратору и кладовщику. Массовая печать доступна администратору, кладовщику и ОТК. Просмотр этикеток — авторизованным пользователям.

Ограничения: количество тары является справочным распределением остатка партии; движения по таре пока не реализованы. При изменении складского остатка распределение не пересчитывается автоматически. Журнал фиксирует подготовку массовой печати, не подтверждает физический вывод на принтер. QR содержит идентификатор `CHEMPRO:CONTAINER:<код>` без публичной ссылки. Массовая печать ограничена 100 этикетками за операцию.

Для установки загрузите файлы в GitHub через браузер, предварительно сделайте резервную копию БД. Не используйте на реальном производстве без тестирования и защищённого постоянного хранилища. Внутренние этикетки не заменяют обязательную маркировку химической опасности.
